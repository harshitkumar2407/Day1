# Codex Demo — Student Portal

Small “college/collage” website with:
- Student register + login
- Dashboard showing student details
- Edit profile + logout

No external npm packages required (built with Node’s built-in modules only).

## Run

```bash
cd "codex demo"
node server.js
```

Then open:
- http://localhost:3000

## Demo account (auto-created on first run)

- Email: `student@example.com`
- Password: `Password123!`

You can also register a new student from the Register page.
